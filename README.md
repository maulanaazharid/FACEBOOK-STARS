# ⭐ Facebook Stars Store

Platform e-commerce sederhana berbasis web untuk layanan pembelian Facebook Stars dengan sistem checkout otomatis terintegrasi ke WhatsApp.

## 🚀 Live Demo
Lihat dan coba websitenya langsung di sini: **(https://facebook-stars.vercel.app/)**

---

## 🌟 Fitur Utama
- **Katalog Layanan:** Menampilkan paket-paket nominal Facebook Stars beserta harganya secara transparan.
- **Auto-Formatted WhatsApp Order:** Ketika pembeli memilih paket dan menekan tombol beli, sistem akan secara otomatis membuat pesan pemesanan yang rapi dan mengarahkannya langsung ke obrolan WhatsApp penjual.
- **Responsive Layout:** Tampilan web yang nyaman diakses melalui perangkat smartphone maupun desktop.

---

## 🛠️ Tech Stack
- **HTML5:** Struktur utama halaman web dan form pemesanan.
- **CSS3:** Penataan gaya visual, warna, dan responsivitas layout.
- **JavaScript (Vanilla JS):** Logika pemilihan paket dan pemrosesan URL WhatsApp API (`wa.me`).
